> An IT help-desk AI agent on Azure AI Foundry that answers from a knowledge base and takes real
> actions through a tool/action API — where IT operations meets applied AI.

## Objective

Demonstrate building a useful, guard-railed AI assistant for IT support: grounded answers from a KB
plus safe, scoped actions — bridging service desk work toward an Applied AI / Forward Deployed track.

## Based on real work

Built an IT help-desk agent on **Azure AI Foundry** with a **live action API**
(`helpdesk-actions-api`) as its tool layer and a knowledge-base index, provisioned for a multi-user
class lab.

## Planned write-up scope

- Agent architecture (Foundry agent + model + KB index)
- Tool/action layer (the action API the agent calls)
- Retrieval over the knowledge base (RAG)
- Guardrails and scoping of actions
- Demo screenshots / sample transcript

## Skills to demonstrate

Azure AI Foundry · agent & tool design · retrieval-augmented generation (RAG) · API integration · IT workflow automation
