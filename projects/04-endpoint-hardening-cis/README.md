> Harden a Windows and a Linux host to a CIS Benchmark baseline, measured with before/after

## Objective

Show I can take a default-configured system and bring it to a recognized security baseline, with
evidence of the improvement and documented, justified exceptions.

## Planned scope

- Baseline assessment (CIS-CAT Lite for Windows, Lynis for Linux)
- Apply the CIS Benchmark via Group Policy (Windows) and scripts (Linux)
- Document exceptions with business/lab justification
- Rescan; report before/after compliance score

## Skills to demonstrate

CIS Benchmarks · security baselines · Group Policy · Linux hardening · compliance scanning · exception management
