> Work a realistic phishing-to-compromise incident end-to-end using the NIST IR lifecycle, and
> produce the artifacts a SOC actually delivers: a playbook and an after-action report.

## Objective

Show I can run an incident from first alert to lessons-learned — analyze the phish, scope the
blast radius, contain and eradicate, recover, and document it for the next responder.

## Planned scope

- Phishing email analysis: headers, sender auth (SPF/DKIM/DMARC), URL/attachment detonation, IOC extraction
- Detection → containment (disable account, isolate host) → eradication → recovery
- Reusable IR **playbook** + **after-action report** with timeline
- MITRE ATT&CK mapping (e.g., T1566 Phishing, T1078 Valid Accounts)

## Skills to demonstrate

Incident response lifecycle (NIST SP 800-61) · phishing/email analysis · IOC handling · containment & eradication · after-action reporting · MITRE ATT&CK
